# Coreweaver Hero Infographic Revision

**Decision:** Replace the floating four-letter path with a structured **Signal Console**. The revision makes the operating model visible without claiming that a live customer system, metric feed, or autonomous process exists.

## Problems in the prior readout

The prior panel combined an abstract spline, four isolated letter nodes, a large status sentence, and a four-item legend. It looked like a generic “AI graph,” did not establish the relationship between the four Coreweaver layers, and competed with the hero headline at the same visual weight.

## Revised model

The console presents a left-to-right, four-stage path: **Entity → Evidence → Distribution → Measurement**. Each stage has a visible state and a compact explanation. Brass identifies the current constraint or decision point; teal marks controlled/connected signal; steel identifies unverified or pending movement. A small method strip names the next legitimate action: map source, bind evidence, release surface, review movement.

The structure stays explicitly illustrative. It does not show performance values, customer information, agent activity, live feeds, outcome claims, certification, or decorative pseudo-data.

## Acceptance criteria

| Criterion | Requirement |
| --- | --- |
| Headline hierarchy | The hero headline remains the first read; the console starts below or beside it as supporting evidence. |
| Method legibility | A reader can name the four signal layers and their directional relationship without reading the next section. |
| Brand system | Obsidian stays dominant; brass indicates decision/constraint; teal indicates signal continuity; no provisional blue/lime colors remain in the console. |
| Accessibility | Decorative linework stays `aria-hidden`; supporting text has adequate contrast; no key meaning relies only on color or motion. |
| Responsiveness | The console preserves stage order and avoids horizontal overflow at 390px. |
| Motion | Any scanning or trace effect is cosmetic, under 300ms, and removed under `prefers-reduced-motion`. |
